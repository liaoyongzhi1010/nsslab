# NIST FIPS 203：ML-KEM 证据摘编

> 资料性质：依据 NIST FIPS 203 整理的课程摘编。回答参数问题时应引用正式标准，而不是依赖模型记忆。

## 算法定位

ML-KEM 是密钥封装机制，用于在公开信道上建立 32 字节共享秘密，再交给对称密码完成加密与认证；它不是直接加密任意长业务消息的算法。FIPS 203 给出 ML-KEM-512、ML-KEM-768、ML-KEM-1024 三组参数，安全强度增加时性能与报文尺寸成本也随之增加。

## Table 3 报文尺寸（字节）

- ML-KEM-512：封装密钥 800；解封装密钥 1632；密文 768；共享秘密 32。
- ML-KEM-768：封装密钥 1184；解封装密钥 2400；密文 1088；共享秘密 32。
- ML-KEM-1024：封装密钥 1568；解封装密钥 3168；密文 1568；共享秘密 32。

## 实现边界

三个参数集的 n 都是 256、q 都是 3329，但 k、噪声参数与压缩参数不同。实现必须只调用有效参数集，并按应用所需安全强度选择。参数名称中的数字不能被简单解释成“位安全强度”，尺寸也不能凭 RSA/ECC 经验类推。
