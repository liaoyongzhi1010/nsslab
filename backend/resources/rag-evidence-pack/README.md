# CryptoLLMLab RAG 证据挑战包

本目录是课堂可离线复现的冻结资料包。平台实际切分、向量化的是 `excerpts/` 下的中文教学摘编；`originals/` 保留发布机构原始 PDF、官方网页文本快照和代码仓文档，供教师和学生核验上下文、页码与版本。

## 目录

- `originals/`：10 份官方 PDF，共 274 页；另有 6 份官方网页或代码仓文本快照。
- `excerpts/`：15 份官方资料的中文教学摘编和 1 份虚构私域案例。
- `manifest.json`：机器可读的来源、日期、路径、大小和 SHA-256。
- `SHA256SUMS`：可直接使用 `shasum -a 256 -c SHA256SUMS` 校验。

## 资料使用原则

1. 中文文件是 CryptoLLMLab 编写的教学摘编，不是官方译本，也不冒充官方原文。
2. NIST、NSA、国家标准全文公开系统和飞腾 PDF 保留原始发布机构标识；网页只保存为 `.txt`，避免离线浏览时执行第三方脚本。使用和再分发时应遵守来源机构声明。
3. “海岚医疗”是虚构案例，没有对应官方 PDF，用于证明私域知识对 RAG 的价值。
4. 课堂实验固定使用本目录版本；需要更新资料时，应重新核验事实并更新清单和校验值。

## 国产密码与 TEE 专题

- 国产商密标准：GB/T 32905—2016（SM3）、GB/T 32907—2016（SM4）、GB/T 35276—2017（SM2 使用规范）、GB/T 39786—2021（信息系统密码应用基本要求）。
- 行业密码规范：国家密码管理局第 45 号公告中的 2023 版 GM/T 标准实施/旧版废止关系，以及第 43 号公告中的 GM/T 0115、0116 测评文件。
- 鲲鹏/openEuler：secGear 24.03 LTS SP4 的 host/EDL/enclave 拆分、鲲鹏证书文件、ARM 构建命令，以及统一远程证明资料。
- 飞腾：PhyTCM/PhyTPCM、PhyCrypto、PhyTEE/PhyCCA 的能力边界，FT-2000/4、D2000、S2500 TEE 方案实例，以及 PSPA 端到云白皮书。

这些资料不仅增加检索数量，还对应四个固定计分基准：GM/T 版本替换、密码应用测评文件角色、鲲鹏 secGear 构建细节、飞腾安全栈边界。题目依赖精确日期、文件名、命令和厂商术语，便于在课堂中量化 Base LLM 与 RAG 的差异。
